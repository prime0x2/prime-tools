## Name

**Prime Tools**

## Short description (≤132 chars; also the manifest description)

Dim, blur or hide any part of a web page. Remembers per site. Local-only, open source.

## Category

- Chrome Web Store: **Accessibility** (alternative: Productivity)
- AMO: **Appearance** and **Privacy & Security**

## Detailed description

> Prime Tools hides what you don't want on screen, whether that's the whole page or just one part of it.
>
> Screen-sharing a dashboard with API keys on it? Streaming with your inbox open? Reading a blinding white page at midnight? Click the toolbar icon and dim it, blur it, or cover exactly the part you need.
>
> **Whole page**
> ✓ Dim or blur the entire page at any strength
> ✓ Remembered per site: every tab on that site follows
> ✓ "Apply on every visit": the effect kicks in as soon as the page starts loading
> ✓ Stays on top of pop-ups, modal dialogs and fullscreen video
>
> **Areas**
> ✓ Hide an area: drag over anything to cover it; the cover scrolls with the page
> ✓ Show only an area: drag over what you want to keep; everything else is covered
> ✓ Fine-tune each one (dim or blur, strength) or remove it with one click
>
> **Keyboard**
> ✓ Alt+Shift+D opens the popup, Alt+Shift+S turns the current site on or off (change them in your browser's shortcut settings)
>
> **Private by design**
> ✓ No accounts, no analytics, no network requests
> ✓ Asks for access to a site only when you choose "Apply on every visit", one site at a time
> ✓ Private windows never save anything
> ✓ Open source (MIT): https://github.com/prime0x2/prime-tools
>
> Note: Blur is a visual cover. For an opaque cover, use Dim at 100%.

## Chrome Web Store: privacy tab

### Single purpose

> Prime Tools covers parts or all of the current web page with a dim or blur overlay, at the user's request, so content stays out of sight.

### Permission justifications

**activeTab:** Lets the extension add its overlay to the current tab only after the user clicks the toolbar button or presses one of its keyboard shortcuts. No access to any other tab.

**scripting:** Injects the overlay script (bundled with the extension) into the current tab when the user opens the popup or uses a shortcut. For sites where the user ticked "Apply on every visit", it registers the same script to run as those sites load, so the effect applies as soon as the page starts loading.

**storage:** Saves per-site settings (site origin, Dim or Blur, strength) and the last-used setting on the user's device. Nothing is synced or transmitted.

**Host permissions (optional_host_permissions: http://\*/\*, https://\*/\*):** Never granted at install. When the user ticks "Apply on every visit", the extension requests access to that single site (e.g. `https://example.com/*`) so the overlay can apply automatically as that site loads. Users can revoke it at any time from the extension's Settings page.

### Remote code

**No.** All code is bundled in the package.
